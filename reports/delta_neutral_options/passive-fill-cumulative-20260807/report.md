# OKX `_UM` 期权被动成交累计研究

> 只使用 OKX 公共 REST/WebSocket 行情；没有账户读取、委托或真实成交。

## 样本

- 窗口一：2026-08-07 09:15:21–09:18:21 UTC，180 秒，264 个 `bbo-tbt` 事件。
- 窗口二：2026-08-07 09:22:48–09:32:48 UTC，600 秒，1,234 个 `bbo-tbt` 事件。
- 合计观察 13 分钟，1,498 个盘口事件；`trades` 事件为 0，连接错误和重连均为 0。
- 每 10 秒创建 join bid、改善 25% 和 midpoint 三种纸面买单；基础结果使用 60 秒 TTL。
- 两个窗口合计 390 组双腿纸面订单，即每种挂价策略 130 组。

另外查询了 OKX 公共 `market/trades` 和 `market/history-trades`：选定的 BTC ATM/OTM 四条腿和 ETH OTM 两条腿均返回 0 笔；ETH ATM 的 Call 和 Put 各只有 3 笔。ETH ATM 合约约在 2026-08-05/06 上市，成交集中在 2026-08-06 09:06、21:00 和 2026-08-07 08:34 UTC 附近，而不是连续市场流。

## 判断

1. 60 秒被动双腿入场没有观察到可执行性。
2. 延长 TTL 偶尔能让 ETH OTM midpoint 双腿穿价，但更快增加单腿裸露，不能视为稳健改善。
3. OTM 降低绝对权利金和 Theta，并未解决相对价差与双腿异步成交问题。
4. 当前不应部署资金。下一项有信息增量的实验应是“首腿成交后立即用永续对冲，再等待第二腿”，并显式计入首腿逆向选择、永续手续费和第二腿超时退出成本。

历史成交记录也意味着继续等待当前这组 BTC `_UM` 合约的盘口，不太可能得到有代表性的成交率；下一轮应先换到公开历史成交更活跃的到期日/执行价，或直接把策略标记为“无可执行市场”并停止报价。

## 边界

- `ask <= limit` 是纸面成交判定，不含真实队列位置；实际被动成交率可能更低。
- 本轮没有收到公开 `trades` 事件，因此没有用逐笔成交提高乐观上界。
- 样本只覆盖一个 UTC 时段和一个到期日前窗口，不能外推到全天或其他到期日。
- 这里只评估入场；完整策略还需承担退出成交、Delta 对冲和手续费。
